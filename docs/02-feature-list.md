# 远远的天空 — 功能点清单

> 每个设计稿页面对应一个功能模块，逐页拆解到可验收的功能点。

---

## 模块 1：首页（对应 `首页.html`）

### 1.1 顶部导航
- F1.1.1 显示 Logo（cloud-sun 图标 + "远远的天空"）
- F1.1.2 桌面端导航菜单：首页 / 文章 / 分类 / 标签 / 关于
- F1.1.3 移动端汉堡菜单（< md 断点）
- F1.1.4 右侧操作区：搜索按钮 + "管理后台"按钮（跳转登录页）
- F1.1.5 当前激活态：首页项为 `text-primary bg-accent`

### 1.2 Hero 轮播
- F1.2.1 3 张幻灯片，最小高度 `md:min-h-[640px]`
- F1.2.2 自动播放，间隔 5000ms
- F1.2.3 鼠标悬停暂停
- F1.2.4 左右箭头手动切换
- F1.2.5 圆点指示器可点击切换，激活态加宽变色
- F1.2.6 文案分层进入动画（title 80ms / subtitle 160ms / actions 240ms）
- F1.2.7 "开始阅读"按钮跳转文章列表
- F1.2.8 支持 `prefers-reduced-motion`

### 1.3 最新文章列表
- F1.3.1 展示 5 篇最新文章
- F1.3.2 卡片结构：封面 + 分类徽章 + 日期 + 标题 + 摘要 + 阅读量 + 标签
- F1.3.3 卡片 hover：上浮 3px + 阴影 + 边框变 primary
- F1.3.4 点击卡片跳转文章详情
- F1.3.5 Scroll reveal 动画

### 1.4 侧边栏
- F1.4.1 搜索卡：输入框 + 搜索按钮，全文搜索文章
- F1.4.2 热门标签卡：标签云，点击跳转（暂不实现，仅展示）
- F1.4.3 分类卡：分类列表 + 文章数，点击暂不跳转
- F1.4.4 关于卡：博主头像（"远"字）+ 姓名 + 简介 + 社交图标
- F1.4.5 侧边栏卡片 hover：上浮 2px + 阴影

### 1.5 搜索结果
- F1.5.1 首页搜索后，结果展示在当前页面文章列表处

## 模块 2：登录页（对应 `登录.html`）

### 2.1 页面背景
- F2.1.1 多层渐变背景（`linear-gradient(160deg, #d4e4f7 0%, ...)`）
- F2.1.2 模糊光晕装饰
- F2.1.3 SVG 云朵装饰，低透明度
- F2.1.4 加载动画：Logo fadeInDown / 卡片 fadeInUp / 页脚 fadeIn

### 2.2 登录表单
- F2.2.1 "返回首页"链接
- F2.2.2 品牌 Logo + "登录管理后台"副标题
- F2.2.3 用户名输入框（user 图标）
- F2.2.4 密码输入框（lock 图标）
- F2.2.5 验证码输入框 + 验证码图片
- F2.2.6 错误提示行（默认隐藏）
- F2.2.7 全宽登录按钮（h-12，主色背景，hover 上浮）
- F2.2.8 底部提示文案 "请输入管理员账号和密码"

### 2.3 交互逻辑
- F2.3.1 验证码图片点击刷新
- F2.3.2 登录成功跳转后台首页，并存储 JWT 到 localStorage
- F2.3.3 登录失败显示错误，刷新验证码
- F2.3.4 默认账号 admin/admin123

## 模块 3：文章管理（对应 `文章管理.html`）

### 3.1 后台布局
- F3.1.1 顶部导航：Logo + "返回前台" + 头像
- F3.1.2 左侧导航：内容管理（仪表盘/文章管理/轮播图管理/分类标签）+ 系统设置（站点配置/AI 配置/OSS 配置/安全策略）+ 底部个人中心
- F3.1.3 当前激活项高亮（primary 背景 + 白字）

### 3.2 页面头部
- F3.2.1 标题 "文章管理" + 副标题
- F3.2.2 "新建文章"按钮（primary 背景）

### 3.3 统计卡片
- F3.3.1 4 张统计卡：文章总数 / 已发布 / 草稿 / 今日新增
- F3.3.2 卡片左边色条（primary / chart-1 / chart-4 / chart-3）
- F3.3.3 大数字 `text-3xl font-semibold tabular-nums`

### 3.4 筛选与搜索
- F3.4.1 状态下拉：全部 / 已发布 / 草稿
- F3.4.2 分类下拉：全部分类 + 动态加载分类列表
- F3.4.3 搜索框（按标题）
- F3.4.4 "批量删除"按钮（destructive 配色）

### 3.5 文章表格
- F3.5.1 列：标题 / 分类 / 标签 / 状态 / 发布时间 / 操作
- F3.5.2 状态徽章：已发布（accent 背景 + primary 圆点）/ 草稿（secondary 背景）
- F3.5.3 操作列：编辑 / 删除（destructive）
- F3.5.4 行 hover：`hover:bg-secondary/50`
- F3.5.5 分页：上一页/下一页 + 页码，当前页 primary 背景

### 3.6 新建/编辑文章
- F3.6.1 标题输入
- F3.6.2 摘要输入
- F3.6.3 Markdown 正文编辑器 + 预览
- F3.6.4 封面图 URL 输入（OSS URL）
- F3.6.5 分类多选
- F3.6.6 标签输入（可选）
- F3.6.7 状态选择：草稿 / 已发布
- F3.6.8 保存 / 取消

## 模块 7：首页整合

### 7.1 轮播图接入
- F7.1.1 从 `Banner` 表查询启用的轮播项，按 sort_order 排序
- F7.1.2 渲染到 Hero 轮播组件

### 7.2 文章列表接入
- F7.2.1 从 `Article` 表查询已发布文章，按 published_at 降序，取前 5 篇
- F7.2.2 渲染到 ArticleCard 组件

### 7.3 侧边栏接入
- F7.3.1 分类卡：从 `Category` 表查询，关联文章数
- F7.3.2 关于卡：硬编码博主信息
- F7.3.3 搜索：调用 `/api/v1/articles?search=xxx`

### 8.1 像素级对比
- F8.1.1 逐页对比设计稿，记录差异

- F8.2.1 所有 hover 效果还原
- F8.2.2 所有 transition 动画还原
- F8.2.3 轮播自动播放 + 手动切换
- F8.2.4 Scroll reveal 动画

### 8.3 响应式
- F8.3.1 移动端（< 640px）布局适配
- F8.3.2 平板（640-1024px）布局适配
- F8.3.3 桌面（> 1024px）布局适配

### 8.4 数据闭环
- F8.4.1 后台新建文章 → 前台首页显示
